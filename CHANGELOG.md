# Changelog Entry Standard

### Problem

### Technologies

- Architecture
- Source code
- Lab
- Automation
- Runbook
- Metrics
- Benchmark
- Incident scenario
- RCA
- Validation

The resulting engineering capability and measurable impact where applicable.

### Lessons learned

Important engineering findings.

### Next step

The next capability or improvement enabled by the work.

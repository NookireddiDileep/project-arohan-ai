# Overview

AI Operations focuses on deploying, managing, monitoring, and operating NVIDIA AI infrastructure in production environments.

This module introduces Kubernetes-based GPU management, GPU virtualization, monitoring tools, inference platforms, and enterprise AI infrastructure management.

The concepts covered in this module prepare engineers to understand how modern AI workloads are deployed and operated at scale.

---

# Learning Objectives

After completing this module, I should be able to:

- Explain Kubernetes in AI Infrastructure
- Understand NVIDIA GPU Operator
- Explain Multi-Instance GPU (MIG)
- Understand Virtual GPU (vGPU)
- Use NVIDIA System Management Interface (nvidia-smi)
- Explain Data Center GPU Manager (DCGM)
- Understand Triton Inference Server
- Explain NVIDIA Inference Microservices (NIM)
- Understand NVIDIA Base Command Manager (BCM)

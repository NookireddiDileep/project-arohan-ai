## Overview

AI Infrastructure forms the largest domain of the NVIDIA Certified Associate – AI Infrastructure & Operations (NCA-AIIO) certification.

This module introduces the NVIDIA technologies that power modern Artificial Intelligence infrastructure, including GPU architecture, high-speed interconnects, networking, memory hierarchy, and enterprise AI platforms.

Understanding these concepts is essential for designing, deploying, and operating scalable AI infrastructure.

---

## Learning Objectives

After completing this module, I should be able to:

- Explain GPU Architecture
- Understand CUDA
- Explain Tensor Cores
- Understand GPU Memory Hierarchy
- Differentiate PCIe and NVLink
- Explain NVSwitch
- Understand DGX and HGX platforms
- Explain InfiniBand
- Understand RDMA
- Explain RoCE
- Understand GPUDirect technologies
